# Portfolio source and published site

## Canonical source

`jdpappdev/jade-polo-portfolio` is the canonical source repository. Its `main` branch is connected to the Netlify site `jade-polo-portfolio`, whose production URL is <https://jade-polo-portfolio.netlify.app/>. The latest Netlify production deploy inspected on 2026-11-28 was built from this repository's `main` branch.

## Legacy GitHub Pages copy

`jdpappdev/jdpappdev.github.io` contains a separate copy of the portfolio files and a README that points to the GitHub Pages domain. It is not the source for the Netlify production site. Treat it as a legacy or alternate publishing copy unless its hosting is intentionally reactivated.

Make portfolio edits in `jade-polo-portfolio`, then review its Netlify deploy. Do not edit both repositories as though they synchronize automatically.
